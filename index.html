Savanna static pages

Three learner pages frozen from the local dev app, for front-end and accessibility work. They run without an application backend; page translation uses Google Translate and requires an internet connection. The hamburger, the week strip, the score details and programme modals, the module switcher and the courses dropdown still work. Frozen dashboard links remain inert; page navigation and assistant Telegram links work, and global search is removed. The assistant prototype cites matching text from the current page. Accessibility settings include opt-in hover-to-read and selected-text reading, using voices already available on the device or browser. Cloud speech needs a deployed Google Cloud endpoint and is not connected yet. Hosted AI, SMS, live screen sharing and shared teacher analytics are not connected.
